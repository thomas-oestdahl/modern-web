En blogg om å bruke moderne, innebygde webplattform-funksjoner.

  • Container Queries i CSS

    Container queries er en ny CSS-funksjon som lar deg lage responsive komponenter. I stedet for å bruke enhetens bredde, kan du definere en container og bruke dens bredde for å bestemme hvordan innholdet skal vises. Dette gjør det enklere å lage fleksible og gjenbrukbare komponenter.

  • Invoker API

    Invoker API er en ny JavaScript-funksjon som lar deg kjøre kode i en isolert kontekst. Dette gjør det enklere å lage sikre og modulære applikasjoner.
