Responsive components with CSS container queries

CSS · No dependencies required

Media queries respond to the size of the viewport. That's fine for page-level layout, but it falls apart for reusable components: a card might live in a wide main column on one page and a narrow sidebar on another. Reaching for a CSS framework's grid system doesn't solve that either — what you actually want is for the component to respond to the size of its own container. That's exactly what CSS container queries do, with no library required.

How it works

  1. Mark an element as a query container with container-type.
  2. Give it a name with container-name (optional, but keeps queries scoped).
  3. Write an @container rule targeting that name.
.resizable-container {
  container-type: inline-size;
  container-name: demo-card;
}

/* Mobile-first: this is the default, narrow layout. */
.demo-card {
  display: flex;
  flex-direction: column;
}

/* Applies once the *container* — not the viewport — is at least 420px wide. */
@container demo-card (min-width: 420px) {
  .demo-card {
    flex-direction: row;
    justify-content: space-between;
  }
}
